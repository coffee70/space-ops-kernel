# Documentation Corpus

This `docs/` directory is the curated documentation corpus for AI Engineer retrieval.

Only content under this directory should be indexed for AI Engineer context retrieval.

Do not index:
- repository README.md files
- AGENTS.md files
- package-local README.md files
- arbitrary markdown outside this docs directory

README.md and AGENTS.md files may contain orientation material for humans and local coding agents, but the canonical indexed documentation lives here.
